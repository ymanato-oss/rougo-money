# 老後資金いくら足りない？診断

老後資金の不足額と、それを埋めるために毎月いくら積み立てればよいかがわかる診断ツールです。

**公開URL: https://ymanato-oss.github.io/rougo-shindan/**

- ブラウザだけで動きます（サーバー・データベース不要）
- 入力した数字はどこにも送信されず、すべて手元のブラウザ内で計算されます
- PC・スマートフォン両対応

## 中身

`index.html` の1ファイルだけで完結しています。
編集の大元（マスター）は Google ドライブの
`AItool / 診断ツール / 金融CTA診断 / モックアップ.html` です。
そちらを直してから `公開用に変換.py` を実行すると、この `index.html` が作り直されます。
