# 老後資金いくら足りない？診断

老後資金の不足額と、それを埋めるために毎月いくら積み立てればよいかがわかる診断ツールです。

**公開URL: https://rougo-money.vercel.app/**

- ブラウザだけで動きます（サーバー・データベース不要）
- PC・スマートフォン両対応
- 計算はすべて利用者のブラウザ内で行われます

## データの記録について

診断結果の傾向を把握するため、「診断する」を押したときに
**入力された数値と診断結果のみ**を統計目的で記録しています（Googleフォーム経由）。

- 記録するもの: 年齢／退職年齢／世帯人数／生活費／臨時支出／貯金／退職金／不足額／流入元／端末種別
- **記録しないもの: 氏名・メールアドレス・IPアドレスなど個人を特定できる情報**
- 記録は1人につき1回のみ（スライダーを動かし直しても増えません）
- 記録に失敗しても診断の動作には影響しません

画面上にもその旨を明記しています。

## 中身

`index.html` の1ファイルだけで完結しています。
編集の大元（マスター）は Google ドライブの
`AItool / 診断ツール / 金融CTA診断 / モックアップ.html` です。
そちらを直してから `公開用に変換.py` を実行すると、この `index.html` が作り直されます。
`main` ブランチに反映すると Vercel が自動でデプロイします。
